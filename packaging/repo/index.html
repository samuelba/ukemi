Ukemi packages

The apt and dnf repositories of Ukemi, a Jujutsu (jj) GUI.

Installing a .deb or .rpm from the latest release adds the repository for you, and your package manager keeps Ukemi up to date from then on. To add it without downloading a package first:

Debian 12+, Ubuntu 22.04+

sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/ukemi.asc https://samuelba.github.io/ukemi/ukemi.asc
sudo curl -fsSLo /etc/apt/sources.list.d/ukemi.sources https://samuelba.github.io/ukemi/deb/ukemi.sources
sudo apt update && sudo apt install ukemi

Fedora

sudo curl -fsSLo /etc/pki/rpm-gpg/RPM-GPG-KEY-ukemi https://samuelba.github.io/ukemi/ukemi.asc
sudo curl -fsSLo /etc/yum.repos.d/ukemi.repo https://samuelba.github.io/ukemi/rpm/ukemi.repo
sudo dnf install ukemi

The metadata is signed with the key in ukemi.asc; the packages are downloaded from the GitHub releases. To stop updates from here, set Enabled: no in /etc/apt/sources.list.d/ukemi.sources or enabled=0 in /etc/yum.repos.d/ukemi.repo.
